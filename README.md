# Maison Alba

Site vitrine d'un bistrot fictif de vingt couverts à Lyon : ardoise du jour, carte de la semaine, producteurs, réservation par plan de salle et horaires.

Site de démonstration conçu par Loan Heron. L'établissement n'existe pas et le formulaire n'envoie rien.

## Contenu

- `index.html` : la page
- `style.css` : les styles
- `script.js` : date du jour, état d'ouverture, plan de salle interactif et formulaire

## Lancer le site

Aucune installation ni compilation : ouvrir `index.html` dans un navigateur.

Le site peut être publié tel quel sur GitHub Pages, Netlify ou tout hébergement statique.
