# Maison Alba

Site vitrine d'un bistrot fictif de vingt couverts à Lyon : nature morte d'automne animée, carte de la semaine illustrée, carte des producteurs à l'échelle, réservation par plan de salle et horaires.

Site de démonstration conçu par Loan Heron. L'établissement n'existe pas et le formulaire n'envoie rien.

## Contenu

- `index.html` : la page et les illustrations (SVG)
- `style.css` : les styles et les animations
- `script.js` : date et état d'ouverture, mouvement de la nature morte, carte des producteurs, plan de salle interactif et formulaire

## Lancer le site

Aucune installation ni compilation : ouvrir `index.html` dans un navigateur. Les polices (Young Serif, Albert Sans) viennent de Google Fonts.

Le site peut être publié tel quel sur GitHub Pages, Netlify ou tout hébergement statique.
